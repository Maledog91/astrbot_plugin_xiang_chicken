基于SerpApi (Google Lens) 的识图找人插件。**核心功能是查推特 (X) 账号，附带推特图床的看图功能。** Kemono仅作为反查推特账号的辅助跳板。

## ✨ 核心功能

1. **多源账号提取**：支持 X (Twitter) 直发、(`@xxx`) 括号精准提取、第三方镜像站 (Sotwe 等) 的账号提取。
2. **Kemono 深度反查**：遇到 Kemono 链接时，自动通过 API + 网页源码双重方式寻找关联的推特/Fanbox 账号（最终目标依然是抓取推特号）。
3. **精准特征过滤与直发优先**：针对 Fapello 等盗图站进行专属规则提取，强力拉黑 TheFap 等干扰站点；直发推文优先，转推（RT）仅作兜底，彻底避免了因转推号或高仿号粉丝多而导致认错人的情况。
4. **AI 灵魂注入**：所有拦截场景均接入 AstrBot 配置的默认大模型。**插件会动态结合用户当前配置的 AI 人格**（如傲娇、高冷等）生成嘲讽。默认提示词已优化防触发 AI 违规审核，且支持在后台自由修改适配。
5. **推特拉图与撤回**：支持抓取目标推特账号置顶及近期推文内的图片（**最多提取10张**）。支持60秒（可配置）自动撤回合并转发消息，并动态获取机器人真实头像与昵称进行发送。
6. **严格权限控制**：5分钟看图时效、防连续刷图冷却、严格拦截白嫖和重复索取（已阅）。

## 📦 安装与配置指南

### 第一步：安装插件

1. 登录 AstrBot 网页后台。
2. 点击左侧菜单的 **插件管理** -> 点击 **添加插件** -> 选择 **从 URL 安装**。
3. 填入本仓库的地址：
   `https://github.com/Maledog91/astrbot_plugin_xiang_chicken`
4. 点击安装，等待提示成功后，确保插件有一个“已打开”状态。

### 第二步：获取并配置 API Key

1. 前往 [SerpApi 官网](https://serpapi.com/) 注册账号，获取你的 API Key（每月有免费额度）。
2. 在 AstrBot 后台 -> 插件管理 -> 找到“小祥找鸡” -> 点击 **配置**。
3. 将 API Key 填入 `SerpApi API Key` 中。

### 第三步：其他重要配置

*   **开启看图功能**：勾选后，才会去下载推特图床的图片（**注意：看图必须挂梯子**）。
*   **看图自动撤回时间**：默认60秒，填 `0` 则不撤回。
*   **黑白名单**：可设置允许触发的群号（白名单），或禁止找鸡/看图的群号。
*   **AI 提示词**：在后台可自由修改各种拦截场景发给大模型的 Prompt，完美配合你机器人的专属人格。

## 🚨 网络代理须知（必看）

*   **查号（识图提取）**：**不需要**挂梯子，直接连通 SerpApi 即可。
*   **看图（下载推特近期十张图片）**：**必须挂梯子**！如果不挂梯子，看图下载 100% 失败。（*插件已默认开启 `trust_env=True`，会自动读取系统的代理环境变量。*）

## 🚀 机器人聊天指令

> 默认指令可在 AstrBot 插件配置中随意修改。

1. **找号**：引用包含人物的图片，发送 `小祥找鸡`。
2. **看图**：**发起识图的人**，在 5 分钟内引用结果消息，发送 `小祥看图`（提取该推特号近期最高 10 张图）。
