基于 SerpApi (Google Lens) 的识图找人插件。**核心功能是查推特 (X) 账号，附带推特图床的看图功能。** Kemono 仅作为反查推特账号的辅助跳板。

## ✨ 核心功能

1. **多源账号提取**：支持 X (Twitter) 直发、转推原博主、第三方镜像站 (Sotwe 等) 的账号提取。
2. **Kemono 深度反查**：遇到 Kemono 链接时，自动通过 API + 网页源码双重方式寻找关联的推特/Fanbox 账号（最终目标依然是抓取推特号）。
3. **智能高频词反推**：当常规方法失效时，自动剥离标题中的垃圾网站名，保留带空格的精准人名，拆分组合去 Google 强搜推特号。
4. **AI 灵魂注入**：所有拦截场景均接入 AstrBot 配置的默认大模型（支持 DeepSeek、ChatGPT 等）。支持后台自定义 Prompt，让 AI 以特定人设生成不同的拒绝提示。
5. **推特看图与撤回**：支持抓取目标推特账号置顶及近期推文内的图片（**最多提取 10 张**）。支持 60 秒（可配置）自动撤回合并转发消息。
6. **严格权限控制**：5分钟看图时效、防连续刷图冷却、严格拦截白嫖和重复索取。

## 📦 安装与配置指南

### 第一步：安装插件
1. 登录 AstrBot 网页后台。
2. 点击左侧菜单的 **插件管理** -> 点击 **添加插件** -> 选择 **从 URL 安装**。
3. 填入本仓库的地址：`https://github.com/Maledog91/astrbot_plugin_xiang_chicken`
4. 点击安装，等待提示成功后，确保插件处于“已打开”状态。

### 第二步：获取并配置 API Key
1. 前往 [SerpApi 官网](https://serpapi.com/) 注册账号，获取你的 API Key（每月有免费额度）。
2. 在 AstrBot 后台 -> 插件管理 -> 找到“小祥找鸡” -> 点击 **配置**。
3. 将 API Key 填入 `SerpApi API Key` 中。

### 第三步：其他重要配置
- **开启看图功能**：勾选后，AI 才会去下载推特图床的图片（**注意：看图必须挂梯子**）。
- **看图自动撤回时间**：默认 60 秒，填 `0` 则不撤回。
- **黑白名单**：可设置允许触发的群号（白名单），或禁止找鸡/看图的群号。
- **AI 提示词**：在折叠面板中可自由修改各种拦截场景发给大模型的 Prompt。

## 🚨 网络代理须知（必看）

- **查号（识图提取）**：**不需要**挂梯子，直接连通 SerpApi 即可。
- **看图（下载推特/Kemono 图片）**：**必须挂梯子**！如果不挂梯子，看图下载 100% 失败。
*(插件已默认开启 `trust_env=True`，会自动读取系统的代理环境变量。)*

## 🚀 机器人聊天指令

> 默认指令可在 AstrBot 插件配置中随意修改。

1. **找号**：引用包含人物的图片，发送 `小祥找鸡`。
2. **看图**：发起识图的人，在 5 分钟内引用结果消息，发送 `小祥看图`（提取该推特号近期最高 10 张图）。
