# astrbot_xiang_chicken (小祥找鸡)

基于 SerpApi (Google Lens) 的全能识图找人插件，支持提取推特账号、反查 Kemono 以及看图功能。

## ✨ 核心功能
1. **多源账号提取**：支持 X (Twitter) 直发、转推原博主、第三方镜像站 (Sotwe 等) 的账号提取。
2. **Kemono 深度反查**：遇到 Kemono 链接时，自动通过 API + 网页源码双重方式寻找关联的推特/Fanbox 账号。
3. **智能高频词反推**：当常规方法失效时，自动剥离标题中的垃圾网站名，保留带空格的精准人名，拆分组合去 Google 强搜推特号。
4. **AI 灵魂注入**：所有违规拦截场景均接入 DeepSeek 大模型。支持在后台自定义 Prompt，让 AI 以特定人设生成独一无二的嘲讽。
5. **看图与撤回**：支持抓取画师置顶及最新的推特图片。支持 60 秒（可配置）自动撤回合并转发消息，防止社死。
6. **严格权限控制**：5分钟看图时效、防连续刷图冷却、严格拦截白嫖和重复索取。

## 🚨 必看：关于网络代理
**抓取推特图床与 Kemono 时，需要确保网络畅通！**
- 插件已默认开启 `trust_env=True`，自动读取系统的代理环境变量。
- 只需保证设备网络能够正常访问推特和 Kemono 即可。

## 🚀 使用方法
> 💡 提示：以下指令均为**默认指令**，可在 AstrBot 后台配置中修改为你喜欢的词汇。
1. **识图找人**：引用包含人物的图片，发送指令 `小祥找鸡`。
2. **看图**：**发起识图的人**在有效期内（默认 5 分钟）引用结果消息，发送指令 `小祥看图`。
